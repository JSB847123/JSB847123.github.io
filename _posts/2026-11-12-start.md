이곳은 배운 내용과 만들어 본 것을 차근차근 남길 공간입니다. 이 글은 블로그를 처음 사용할 때 참고할 수 있도록 넣어 둔 **시작 안내 글**입니다. 제목과 본문은 언제든 바꿀 수 있습니다.

## 새 글 올리는 방법

1. [블로그 저장소](https://github.com/JSB847123/JSB847123.github.io)에 접속합니다.
2. **Add file → Create new file**을 누릅니다.
3. 파일 이름을 `_posts/2026-11-13-my-note.md`처럼 입력합니다. 앞부분의 날짜는 실제 작성 날짜로 바꿉니다.
4. 아래 양식을 붙여 넣고 제목과 본문을 수정합니다.
5. **Commit changes**를 눌러 저장합니다. 배포가 끝나면 글 목록에 자동으로 나타납니다.

```markdown
---
title: "새 글의 제목"
date: 2026-11-13 09:00:00 +0900
categories: [배움]
description: "이 글의 내용을 한 문장으로 소개합니다."
---

오늘 배운 내용을 적습니다.

## 기억하고 싶은 내용

- 첫 번째 내용
- 두 번째 내용
```

> 미래 날짜로 작성한 글은 그 시간이 되어야 공개됩니다. 바로 올릴 때는 현재 또는 과거의 날짜와 시간을 사용하세요.

## Markdown의 기본 문법

- `## 제목`: 소제목
- `**강조할 말**`: 굵은 글씨
- `- 항목`: 목록
- `[링크 이름](주소)`: 링크

## 기존 글과 블로그 이름 바꾸기

기존 글은 저장소의 `_posts` 폴더에서 파일을 열고 연필 모양의 편집 버튼을 누르면 수정할 수 있습니다.

블로그 이름과 설명은 `_config.yml`의 `title`과 `description`에서, 소개 글은 `about.md`에서 바꿀 수 있습니다.

작은 기록 하나부터 시작해 보세요.
